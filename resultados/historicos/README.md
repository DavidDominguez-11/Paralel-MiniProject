# Resultados históricos

Esta carpeta conserva salidas y reportes de iteraciones anteriores del proyecto.
No representan necesariamente el comportamiento de la versión actual del simulador.

- `ITERACION_*_RESULTADOS.md`: reportes de desarrollo por iteración.
- `run-*.txt`: ejecuciones comparativas con diferentes cantidades de hilos.
- `test-results.txt`: salida histórica de pruebas.
